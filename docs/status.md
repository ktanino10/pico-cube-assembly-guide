# 現在状況と根拠の読み方

記録整理日：2026-11-07。これは公開文書の更新日であり、製造・購入・取引の日付ではありません。

## 現在の結論

既存図面・Gerberをもとに、1号機ESP32版と2号機Pico版の編集可能なKiCad 10データを再構築しています。主対象はPico版です。再構築データの照合と検査には進捗がありますが、**回路の実機動作、部品の実装適合、熱設計、全工程の組み立て成立は確認済みではありません。**

実装委託へ進んでいるとの申告があります。ただし最終メーカー承認BOM・仕様、製造完了、納品、通電動作は未確認です。見積候補が実際の製造確定版になったと推定しません。既知の保留は、メーカー合意資料などの根拠なしに解決扱いにしません。

## 根拠の分類

| 表記 | 意味と限界 |
|---|---|
| 記録上確認 | 元データを扱った再構築・検査作業の結果として報告された事項。この文書の公開時に全CAD検査を再実行したという意味ではない |
| 計算 | 明示した値・仮定に対する算出結果。公差、過渡、故障、実物測定を含まない場合がある |
| 候補 | 見積・設計比較用の案。採用・調達・製造承認を意味しない |
| 未確認 | 必要な実物、メーカー資料、合意仕様または検証が揃っていない |
| 申告 | 実施したとの報告。製造側の記録や実機で裏付けられた状態とは分ける |
| 公開資料 | 作者、メーカー、サービスの公開説明。対象版・型番との一致を別途確認する |

元の非公開資料は転載せず、技術的な観察と検査結果を独自の説明に整理しています。[公開出典](publication.md)は一般仕様や背景を参照するためのもので、この再構築物の合格証ではありません。部品価格・在庫・規約・現行図面を公開時点で全面再確認したものでもありません。

## 保留一覧

| 対象 | 現在の状態 | 解決に必要なもの |
|---|---|---|
| 基板再構築 | 記録上、接続照合・ERC・DRCなどは一致／指摘0 | 実機電気設計と製造確定版の別途確認 |
| ソケットと基板穴 | FIT HOLD：候補の推奨穴寸法と基板値が不一致 | 仕上がり穴公差のメーカー確認、または別MPNの評価 |
| 7805 | FIT / THERMAL HOLD | 現行パッケージ図、負荷、放熱、コンデンサー、保護回路の確認 |
| 電池ハーネス | コネクター単体候補のみ | 線材、極性、電流、絶縁、保持方法の仕様 |
| モーター・エンコーダー | 推奨型番は未確定 | 正確な型番仕様、電圧・電流・論理レベル・機械寸法 |
| PCBと支持具 | 穴パターンに1穴0.186 mmの差 | 実物・公差・固定方式・スペーサーの検証 |
| 組み立て工程 | 旧動画撤回。一部のモデル経路のみ検査済み | 全経路、工具、締結、保持、公差、実物での成立確認 |
| 製造・実装 | 委託へ進んでいるとの申告 | 最終メーカー承認BOM／仕様と製造側の確認 |
