# Picoの接続・電気条件

**原回路を保持した再構築上の接続記録です。安全な配線・通電を保証する手順ではありません。** 電池、実物端子の極性、論理レベル、保護、負荷条件を未確認のまま接続しないでください。

## 電源と外部端子

対象条件は3S LiPo、公称11.1 V・最大12.6 Vです。Picoは20 pinソケット2本による装着を想定しています。J2〜J4は各8 pinのモーターCTR／RH／LH、J5は外付MPU6050の8 pinで、2.54 mmメスソケットが候補です。

J1の電池入力穴はピッチ5.08 mm・穴径1 mmです。電池側の刻印としてXT30U-Fが観察され、それに対する基板側ケーブルのコネクター候補はXT30U-Mですが、これはハーネス完成品の確定を意味しません。4 pinのバランス端子は電源入力に使用しません。線径・長さ・絶縁・引張対策・許容電流・極性は未確定です。

## モーター接続表

ピン番号で照合してください。表の並びだけで実物の見込方向やコネクター左右を判断しません。

| Pin | J2：CTR | J3：RH | J4：LH |
|---:|---|---|---|
| 1 | VBAT | VBAT | VBAT |
| 2 | GND | GND | GND |
| 3 | START_STOP / GP18 | START_STOP / GP19 | START_STOP / GP20 |
| 4 | PWM / GP2 | PWM / GP4 | PWM / GP6 |
| 5 | DIR / GP3 | DIR / GP5 | DIR / GP7 |
| 6 | +5V | +5V | +5V |
| 7 | ENC_A / GP10 | ENC_A / GP12 | ENC_A / GP14 |
| 8 | ENC_B / GP11 | ENC_B / GP13 | ENC_B / GP15 |

PicoのGPIOは3.3 V系です。エンコーダーを5 Vで給電する構成であっても、出力がPicoへ直接接続できる論理レベルとは限りません。

## 分圧・レギュレーター

| 部品・端子 | 再構築上の値／接続 |
|---|---|
| R1 | 1.5 kΩ、VBAT → GP26 |
| R2 | 470 Ω、GP26 → GND |
| C1 | 0.1 µF、入力VBAT–GND |
| C2 | 33 µF、出力+5V–GND |
| U2 | 7805、IN / GND / OUT |
| Pico VSYS | +5V |

作者の別時期の公開記事には15 kΩ／4.7 kΩの記述がありますが、この再構築では提供された回路の1.5 kΩ／470 Ωを保持しています。比率が同じでも消費電流は同じではありません。

抵抗の公称値と12.6 Vを使う計算では、分圧電流は約6.40 mA、R1の消費は約61 mW、R2は約19 mWです。これは公称条件の計算であり、故障・過渡・温度・抵抗公差を含む保証ではありません。

3S電源から5 Vを得る7805の損失は、おおむね`(12.6 − 5) × Iout + 静止損失`です。負荷、放熱器、必要なコンデンサー条件、逆流保護は未確定です。USBと電池を併用したときの逆流、無給電GPIOへの注入も未検証です。

## モーター選定の状態

Nidec **24H055M020**が候補として挙がっていますが、製造元の該当型番仕様は未取得です。CAD中の`BLDC_Motor_24H`という名称だけでは同一型番と判断できません。

対象のPicoコードは、ドライバー内蔵BLDCのPWM duty・方向・start/stopとABエンコーダーを前提とし、反転PWMを使用しています。ドローン用3線モーターや通常のステッピングモーターを直接接続する構成ではありません。

作者はステッピングモーターを試した後、Picoでの問題と後期のBLDC測定を報告しています。これは特定代替品の適合保証ではありません。`Bl4825o`候補も停止機能・フィードバック仕様が不明で、代替推奨しません。

最大12.6 V、ピーク／ストール電流、3.3 V論理、エンコーダー出力レベル、軸径・形状・穴間隔を、実物とメーカー資料で照合するまでは推奨型番を確定しません。
