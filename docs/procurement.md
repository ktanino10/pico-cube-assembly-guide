# 製造依頼・調達時の注意点

個別の取引を再現する記録ではなく、製造依頼で区別すべき状態と技術的な教訓をまとめています。**候補表より最終メーカー承認BOM／仕様を優先してください。**

## 受付と製造承認を分ける

Gerberのアップロード画面が`100% Success`になり、2層基板と寸法が認識されても、工場の製造承認とは限りません。Picoのサイト表示が78.7 mmに丸められていても、元データの78.73 mmを勝手に変更しません。

製造依頼資料では、BOMのメーカー・MPN・数量・Ref・パッケージを明確にします。THTをcentroidの対象外にできる案内があっても、極性・ピン1・実装方向図の必要性は残ります。対象のサービスとメーカー担当工程の最新要件を確認します。

## 品番未確定から見積候補更新まで

品番が未確定の資料をengineering reviewへ提出した段階では、MPN欠落により見積できないとの指摘がありました。その後、Rev02で正確なMPNを入力しましたが、**正確な文字列が埋まることと、FIT / THERMAL HOLDの解決は別です。**

ログイン後の提出処理ではGerber・BOM・参考PDFの3種類についてアップロード成功を確認し、レビュー提出へ進んだという作業記録があります。支払いの代理操作は行っていません。これらの受付記録と、その後に実装委託へ進んだとの申告は別の状態として扱います。製造完了やメーカーの最終合意まで推定しません。

## フォーム操作の教訓

備考欄に600文字の制限がありました。重要な保留事項を省略して「確定」と見せるのではなく、制限内の要点と別途の仕様資料を整合させる必要があります。

画面のDOM上で数量の表示値だけを変更しても、内部フォーム値が同期されず、0やInfinityを含む不正な計算表示になった例がありました。入力欄の正規の入力操作で状態を更新し、サービスが対応する裸基板の最小数量条件を満たしたうえで再計算する必要があります。対象画面で扱えた最小値は5枚でしたが、これはサービス上の条件であり、個別の購入数量ではありません。表示だけを書き換えて成立と判断しません。ここでは個別の購入数量や金額を掲載しません。

書類が必要な場合は、署名対象の範囲（全注文を含むのかなど）、個人向けの記入欄、必要な本人確認情報の提出方法を、サービスの正式な窓口と現行条件で確認する必要があります。この文書は署名を推奨するものでも、法令適合を断定する法的助言でもありません。個人の提出状況や書類内容は公開対象にしません。
