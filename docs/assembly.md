# 組立・CAD検査・メディア

**全工程の実行可能な組み立て手順は未確定です。** 静止状態の形状照合、一部の移動経路の検査、工具・締結・実物の確認は別々の課題です。ここにある試行経路を作業手順として使用しないでください。

## モデルの範囲

FreeCADで元のAssy.stepの83個の葉solidをグローバル位置を保持して取り込み、Blenderで表示用メディアを制作しました。Fusionは起動したもののbridge接続がなく、Fusionで生成した成果とは説明しません。

基板外形と穴はnativeデータを使用していますが、電子部品外形は概略です。IMU本体・配線・電池・ネジ全数・工具・治具はモデル化されていません。CG上の基板は支持具から6 mmオフセットした仮配置であり、6 mmを指定スペーサー寸法と解釈しません。

公開中の16秒の全体外観動画は、全部品を固定してカメラだけを周回させています。取り付け・挿入・締結の工程を示さず、実物動作や通電・回転の安全性を保証しません。

## 基板取付穴と支持具

Picoの取付穴中心は、基板データ内の座標系で次の値です。単位はmmです。

| 穴 | X | Y |
|---|---:|---:|
| A | 3.986 | 3.986 |
| B | 44.45 | 3.986 |
| C | 44.45 | 74.93 |
| D | 3.986 | 74.744 |

片側のピッチは70.758 mm、他方は70.944 mmで、支持具は両側とも70.944 mmです。1穴の差は0.186 mmです。最小二乗で位置合わせしても最大残差は約0.130 mmでした。位置合わせで差が分散することと、取り付けが成立することは同じではありません。印刷・ネジ・穴の公差による取り付け成否は未検証です。

## 動画を撤回した理由

外枠を先に置く動画を、内側を先にするv2へ変更しましたが、順番の変更だけでは実際に組みやすい工程になりませんでした。必要なのは、非現実的な部品の通り抜けがなく、作業中に保持でき、工具が入り、固定できる手順です。

元の動画とv2はどちらも撤回しています。既知の干渉を持つ動画や、未検証の動きを全工程の組み立て手順として再公開しません。

## 検査結果と証明範囲

以下は対象の仮モデルに対する**作業記録上の結果**です。対象外の形状や実物公差まで含む証明ではありません。

| 検査 | 結果 | 限界 |
|---|---|---|
| 完成位置の静的検査 | 180候補ペアで、0.01 mm³を閾値とする体積交差を検出せず | モーター内部、元データの固定部品、PCB内だけのペアなどを除外。移動中を保証しない |
| v2の基板挿入 | XYZ各+30 mmから0へ動かす途中、各+25 / +20 mmで先置きIMU支持具に干渉 | 基板本体の交差は約517.54 / 122.61 mm³。完成位置だけの検査では見落とす |
| 基板先→IMU支持具後の2並進 | 距離関数のLipschitz性を使う区間下限判定でモデル上の分離を確認 | epsilon 0.02 mm。基板の保守下限1.45 mm、後付IMU支持具8.01 mm。工具・公差・全工程の検査ではない |
| 外側20対象、各9位置 | ホイール3個が先置きハブのフランジに干渉。他17対象はサンプル点で交差なし | ホイールの干渉は残距離5 / 2 / 1 / 0.5 mmの位置。サンプル間の連続経路は未証明 |
| ホイール＋ハブを先に一体化する案 | 3軸、各9点のサンプルで交差なし | 連続経路、ハブ自体の組み立て、工具・固定方法は未検証 |

交差体積は「基板本体」など対象形状の範囲を明示しています。部品群全体の集計値と混同しません。

サンプル点での無干渉は、その点と点の間も無干渉だという意味ではありません。区間下限判定は対象とした2並進についての、モデル内の限定的な確認です。残る外側部品やサブアセンブリまで保証を拡張しません。

現物を使わない段階ではCADで確認できる範囲を先に進めますが、工具アクセス、締結順、保持、ハブの取り付け、公差、未モデル部品の空間を解決しなければ全工程を公開できません。
