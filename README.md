# Picoキューブ 組み立て参考ガイド

2号機Pico版の、内側から外側へ配置する順序を確認する日本語ガイドです。
内部の部品、コーナーとモーター側の部品、最後に残る外側の3面、という順序で説明します。

動画は参考アニメーションであり、実物の挿入経路・工具アクセス・締結の可否を検証した手順書ではありません。
基板と支持部の穴パターンには1か所で0.186 mmのずれがあり、基板固定とスペーサー寸法は暫定です。
部品外形は説明用です。IMU本体・ケーブル・バッテリーを含まず、動作可能な完成構成でも、安全な通電・回転を保証する資料でもありません。

## 構成

ビルド不要のHTML・CSS・JavaScriptと、公開対象の動画2本・注記付きCG5枚のみを掲載します。
外部スクリプト・CDN・解析ツールは使用しません。動画は自動再生しません。
GitHub Pagesでは`main`ブランチのルートを配信します。

本体の修正版動画は41秒、960×768です。内部の配置を0〜12秒、
コーナーとモーター側を15〜27秒、最後の3面を30・33・36秒から表示します。
章リンクは対応時刻へ移動して一時停止し、自動再生はしません。
JavaScriptが無効、または動画がまだ読み込まれていない場合は、時刻付きのMP4リンクとして動作します。
