# Picoキューブ 組み立て参考ガイド

2号機Pico版の配置参考資料と、組み立て工程の検証状況を掲載する日本語サイトです。
要求は「内側から」という順番ではなく、非現実的な干渉がなく実際に組み立てやすい手順です。
従来の本体アニメーションには挿入経路の干渉が見つかったため、動画と章別の手順案の公開を停止しました。
完成位置の確認だけでは不十分で、移動中の干渉・締結・工具アクセスの確認が必要です。
配置順だけを実行可能な組み立て手順として扱いません。

動画は参考アニメーションであり、実物の挿入経路・工具アクセス・締結の可否を検証した手順書ではありません。
基板と支持部の穴パターンには1か所で0.186 mmのずれがあり、基板固定とスペーサー寸法は暫定です。
部品外形は説明用です。IMU本体・ケーブル・バッテリーを含まず、動作可能な完成構成でも、安全な通電・回転を保証する資料でもありません。

## サイトの構成

ビルド不要のHTML・CSS・JavaScriptと、全体外観の参考動画1本・基板の配置参考動画1本・注記付きCG4枚・動画ポスター1枚を掲載します。
外部スクリプト・CDN・解析ツールは使用しません。動画は自動再生しません。
GitHub Pagesでは`main`ブランチのルートを配信します。

全体外観動画は16秒・960×768・音声なしで、部品をモデルの完成配置に固定してカメラだけが周回するものです。
取り付け順・挿入経路を示す組み立て動画ではなく、実機の完成や安全な動作を確認した映像でもありません。
基板は仮配置、電子部品外形は概略で、IMU本体・配線・バッテリーは省略しています。

本体の工程は未確定です。元形状での移動中の干渉、サブアセンブリ、締結順、
工具の作業空間、作業中の保持方法を確認し、根拠のある範囲だけを手順として掲載します。
